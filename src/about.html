ABOUT CLASHPANEL

Built for the people doing the organising.

Running CWL gets messy fast when rosters, availability, attacks and multiple clans all live in different places. ClashPanel exists to keep that workflow connected.

Start for freeSee the CWL Planner
01 / THE PROBLEM

Clan leadership is mostly context switching.

A CWL plan can start in a spreadsheet, availability in Discord, player history in another tool and the live league somewhere else. None of those pieces are individually difficult; keeping them consistent is.

02 / THE PRODUCT

Useful first. Connected second.

Each ClashPanel tool should solve a real clan workflow on its own. The extra value comes from reusing the same roster, clan relationships and availability across planning, live CWL and review instead of entering everything again.
