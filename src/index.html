One continuous workflow

Prepare the roster, make the plan, then run CWL from the same data.

The Planner and Operation Board are built as one flow, while Clan Families keep availability and shared clan data connected before CWL starts.

  1. 01

    Prepare

    Collect players and availability

    Load players by tag, account, friend, spreadsheet or Clan Family. Pull CWL poll availability into the same free roster.

  2. 02

    Plan

    Build or optimize the multi-clan plan

    Use Auto Plan for a complete distribution, Optimize Plan for targeted improvements, or keep full manual control over roles and daily lineups.

  3. 03

    Run

    Follow every round live

    Track the current war, league position, player participation, projected outcomes and bonus recommendations from Operation Board.
